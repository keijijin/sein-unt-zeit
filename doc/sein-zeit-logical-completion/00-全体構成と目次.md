# 『存在と時間』の内的論理による完結構成

本稿は、1927年刊『存在と時間』**既刊部分（第一部第一編・第二編）**にすでに展開されている概念運動（ダザイン、世界性、配慮、死、良心、決断性、時間性、歴史性、流俗時間・内時間性など）から**論理的に必然化される**未完部分の、章立て・各節の結論一句・論述スケッチである。外部文献への依拠は原則としない。

## 完結の論理的位置

既刊は、(1) 存在の意味を問う、(2) その手がかりとして存在理解をもつ存在者＝ダザインを分析する、(3) ダザインの存在論的構造の根拠として**時間性**を明示する、まで到達する。ここで残るのは、(4) 時間性を単なる「存在者の属性」ではなく**存在理解一般の地平**として展開し、(5) 問いのタイトル順を反転させて**時間から存在へ**と視座を転じ、(6) 伝統的存在論がその地平をどう**覆い隠して**きたかを解体することで、(7) 序論で立てた**同じ問い**を、より根源的な鋭さで立て直す、という円環である。
